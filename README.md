# Freedom Broker · Conversation Quality Analytics (CQA)
### Прототип системы автоматической оценки качества диалогов для контакт-центра

Решение разработано в рамках **Freedom Broker CQA Hackathon** (24-часовой спринт). 
Проект реализует двухконтурную систему оценки коммуникаций операторов (чаты и звонки на RU, KZ, EN) с архитектурой, готовой к встраиванию как веб-компонент в **Microsoft Dynamics 365**.

---

## 🚀 Быстрый старт за 2 шага

### Шаг 1: Установка зависимостей
Убедитесь, что установлен Python 3.10+:
```bash
pip install -r requirements.txt
```

### Шаг 2: Запуск сервера
```bash
python app.py
```
После запуска откройте в браузере: **`http://localhost:8000`**

## 🧠 Подключение ИИ (Бесплатные модели)

В проекте реализована модульная архитектура адаптеров (`evaluator.py`), поддерживающая бесплатные режимы работы без затрат на инфраструктуру:

1. **Google Gemini 1.5 Flash (Бесплатный тариф Google AI Studio):**
   * Преимущество: лучшая поддержка казахского языка (KZ), русского (RU) и английского (EN), бесплатный лимит 15 запросов в минуту / 1500 в день.
   * Как включить: задайте переменную окружения `GEMINI_API_KEY="ваш_ключ"` в файле `.env`.
2. **Groq (Llama 3.3 70B Versatile):**
   * Преимущество: ультрабыстрая генерация (<1 сек) на бесплатном ключе Groq.
   * Как включить: задайте `GROQ_API_KEY="ваш_ключ"`.
3. **Локальная модель (Ollama / Qwen 2.5 7B):**
   * Полностью автономная работа без интернета и утечки клиентских данных.
   * `ollama run qwen2.5:7b` (эндпоинт `http://localhost:11434`).
4. **Встроенный детерминированный движок (Smart Offline Engine):**
   * Включен по умолчанию при отсутствии внешних ключей. Позволяет мгновенно и без сбоев провести демонстрацию жюри даже при отсутствии подключения к сети.

## 🛠 Архитектура и соответствие регламенту

| Требование хакатона | Реализация в проекте |
| :--- | :--- |
| **Интерфейс под Dynamics 365** | HTML5, CSS3 (Segoe UI, палитра Freedom Broker `#0a4d3c`, карточный дизайн Fluent UI). Адаптирован для размещения внутри `iframe` или WebResource формы Dynamics 365. |
| **Поддержка 3 языков** | Русский (RU), Казахский (KZ), Английский (EN). |
| **Каналы коммуникации** | Текстовые чаты (`agent chat`) с метками `MM:SS` и звонки (`voice call`) с `ISO 8601` и встроенным аудиоплеером. |
| **Реплики бота и системы** | Выделены цветом и тегами, учитываются моделью исключительно как контекст обращения. Оценивается только реплика оператора. |
| **Интерактивные доказательства** | Клик по цитате в карточке оценки автоматически скроллит транскрипт и подсвечивает точную реплику оператора желтой анимацией. |
| **Правило N/A и веса** | Веса неприменимых критериев пропорционально перераспределяются между активными. Итоговый балл всегда нормируется к 100%. |
| **Грубая ошибка (Fatal flaw)** | Выделена красным предупреждением; при нарушении критического регламента итоговый балл обнуляется. |
| **Контур апелляций** | Оператор подает несогласие с комментарием $\rightarrow$ Супервизор во вкладке апелляций видит контекст $\rightarrow$ Принимает решение с мгновенным пересчетом итога. |
| **Стресс-тест 23-го часа** | Вкладка «Конструктор чек-листа» позволяет на лету добавить/заменить критерий и применить его на диалогах без перезапуска сервиса. |
| **Защита от CORS** | Встроенный эндпоинт `/api/fetch_organizers_data` запрашивает данные DEV/контрольного сета через бэкенд. |
