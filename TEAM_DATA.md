# Совместная работа с данными

Это приватный репозиторий исходников. Для коллеги достаточно доступа Write, а не Admin. Создавайте ветки и Pull Request для изменений.

- Нечувствительные синтетические примеры можно добавлять в `data/examples/`.
- Реальные диалоги, записи, персональные данные и подписанные ссылки не добавляйте в Git.
- DEV JSON храните локально как `dev_data.json`; он исключён из Git.
- API-ключи задавайте локально через `.env`, не через исходники.
- Репозиторий не является общей базой работающего приложения: у каждого локального запуска своя SQLite. Для совместного веб-доступа потребуется отдельный защищённый сервер.

GitHub: Settings → Collaborators → Add people → точный username коллеги. После принятия приглашения она сможет создавать ветки и добавлять разрешённые данные через Add file → Upload files.
