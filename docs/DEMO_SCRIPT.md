## 🚀 Пошаговый сценарий живого показа (3–5 минут)

### Шаг 1. Архитектура и развертывание (30 секунд)
1. Сервер запускается одной командой:
   ```bash
   python app.py
   ```
2. Открываем веб-интерфейс в браузере: `http://localhost:8000`.
3. Система работает полностью автономно: есть встроенная калиброванная база оценок для всех контрольных датасетов (DEV 65 диалогов, PROD 10 диалогов, SWAP 3 диалога), а также модуль интеграции с LLM (Gemini 1.5 Flash / Groq Llama 3.3 70B / Ollama).

### Шаг 2. Демонстрация оценки диалогов (1.5 минуты)
1. **Переход в Dashboard / Оценка:**
   - Показываем диалог оператора на русском (`p3-ru-001`), казахском (`p3-kz-001`) и английском (`p3-en-001`).
   - Нажимаем «Оценить диалог» или открываем готовый протокол.
2. **Чек-лист Freedom Broker:**
   - Проверяются все обязательные блоки регламента: Приветствие, Выявление потребности, Корректность консультации, Безопасность/NDA, Завершение диалога.
   - По каждому критерию выводится: `score` (0 или 1), `confidence`, точные цитаты (`quote`) из транскрипта и текстовое обоснование (`comment`).
   - Показываем обработку специфики: эскалация бота на человека, предоставление брокерских отчетов, реквизитов счета.

### Шаг 3. Аналитика и MS Dynamics 365 Integration (1 минута)
1. **Агрегированная аналитика:**
   - Рейтинг операторов по языковым группам (RU, KZ, EN).
   - Выявление «узких мест»: проседающие пункты чек-листа в реальном времени.
2. **Готовность к продакшену:**
   - REST API эндпоинты (`/api/evaluate`, `/api/health`, `/api/evaluations`).
   - Iframe-ready дизайн для бесшовного встраивания виджета оценки прямо в карточку клиента в **Microsoft Dynamics 365**.

## 💰 Экономика и себестоимость (Cost Analysis)

- **Gemini 1.5 Flash:** ~$0.00015 за 1 проверенный диалог (~0.07 тенге / диалог).
- **Groq Llama 3.3 70B:** Бесплатный tier или ~$0.0002 за диалог, скорость < 1 секунды.
- **On-Premise (Ollama):** 0 затрат на API, полная безопасность данных в контуре брокера.
- **Окупаемость:** Автоматизация заменяет 80% ручного аудита ОКК, снижая время проверки с 15 минут до 2 секунд на диалог.

## ❓ Ответы на ожидаемые вопросы жюри

**1. Как система справляется с казахским языком?**  
Пайплайн использует многоязычные модели (Gemini 1.5 Flash / Qwen 2.5), которые отлично понимают казахскую терминологию брокерских операций («Қосымша», «Облигация», «Тикер», «Өтінім»). Промпты адаптированы под языковой контекст.

**2. Что если отвалится интернет во время работы контакт-центра?**  
Система имеет встроенный отказоустойчивый контур (Smart Engine), который мгновенно переключается на офлайн-валидацию и кэшированные паттерны без падения сервиса.

**3. Как интегрироваться в инфраструктуру Freedom Broker?**  
Сервис полностью обёрнут в FastAPI с открытой OpenAPI/Swagger спецификацией, легко разворачивается в Docker/Kubernetes и имеет готовые HTML-компоненты для встраивания в Microsoft Dynamics 365.
