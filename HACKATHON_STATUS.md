# Обновление по официальному чек-листу

Источник: CQA_Chat_Quality_Checklist.pdf, 3 страницы, предоставлен пользователем.
Критерии сохранены в official_checklist.json: веса 10/15/20/20/15/15/5/0.
№4: 0/5/10/15/20; №6: 0/4/7/10. N/A только №2/3/4/7 с причиной.
Грубые ошибки: Да=1, отдельный флаг, не обнуляет итог. Итог 2 знака; без применимых весов null.
При первом запуске старые c1..c8 заменяются официальными, исторические снимки оценок сохраняются. Последующие изменения пользователя не затираются.

## Запуск
Mac: `bash start.command`, затем http://127.0.0.1:8000.
Docker: `docker compose up --build` (в этой среде запуск Docker не проверялся).

## Важно
Без настроенной LLM оценки НЕ выполнены: интерфейс требует проверки; нули технические, не доказанные нарушения. Нет фиктивных цитат. Можно настроить LLM через .env после согласования передачи диалогов выбранному провайдеру.
Официальный документ предназначен для чатов; использование для звонков требует отдельного регламента.
Реальные диалоги и подписанные ссылки удалены из проекта и не включены в новый архив. Только синтетические примеры seed_data.py.
Перед публикацией нужен отдельный security-review; этот прототип предназначен для локального демо.
