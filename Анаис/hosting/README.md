# Панды судного дня — hosted CQA

Облачная версия приложения: Worker ES module, D1 и R2. Публичный интерфейс: https://pandy-sudnogo-dnya-cqa.restfulrhubarb1.chatgpt.site/.

В исходниках только четыре придуманных учебных сценария. Локальные рабочие записи и `.env` не входят в пакет. Данные посетителей разделяются сессионной cookie; изменения фиксируются транзакционно с проверкой версии.

## Сборка и тесты

```powershell
pnpm install --ignore-scripts
node scripts/build.mjs
node --test tests/worker.test.mjs
```

`src/` содержит подготовленные бизнес-правила и адаптер модели. `scripts/prepare.mjs` используется только для синхронизации с исходной локальной структурой проекта; автономная сборка использует уже включённый `src/` и не требует DEV-файлов.

Схема описана в `db/schema.ts`; миграции Drizzle — в `drizzle/`. При изменении схемы запустить `node node_modules/drizzle-kit/bin.cjs generate`. Опубликованные миграции не менять задним числом.

`.openai/hosting.json` связывает проект с хостингом и объявляет `DB`/`BUCKET`. Публикация выполняется через Sites: точные исходники сохраняются в репозитории хостинга, собирается архив `dist`, сохраняется версия и публикуется проверенная версия. Секреты настраиваются через окружение хостинга, не через исходники.

## Серверное окружение

`OPENAI_API_KEY` или `LLM_API_KEY`, `LLM_MODEL`, `LLM_URL`, `LLM_REASONING_EFFORT`, `LLM_MAX_OUTPUT_TOKENS`, `INPUT_PRICE_PER_MILLION`, `OUTPUT_PRICE_PER_MILLION`. Для загрузки презентации служит отдельный секрет `UPLOAD_TOKEN`. Его нельзя включать в клиентские запросы или публичные файлы.

Публичная демонстрация не включает подписанный адрес набора организаторов. `DATASET_URL` задаёт администратор отдельно, если требуется импорт через group_id.

Презентация загружается администратором в R2 через защищённый `PUT /admin/presentation`; публичный `GET /presentation.pptx` отдаёт файл. На посетителя установлено 100 запросов модели в сутки, на сайт — 1000. Лимит самого провайдера может быть ниже. При долгом `Retry-After` сервер сообщает о квоте и не выполняет бесполезные повторы.
