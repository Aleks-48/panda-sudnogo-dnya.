# CQA — облачная версия

Рабочий сайт: https://cqa-quality-control.restfulrhubarb1.chatgpt.site/. Worker ES module и D1; интерфейс, данные пользователей и резервные копии. Команда и презентация в интерфейсе отсутствуют. Презентация — отдельный файл в соседней папке presentation.

## Проверка и сборка

```powershell
pnpm install --ignore-scripts
node scripts/build.mjs
node --test tests/worker.test.mjs
```

Используются подготовленные src/ и public/. scripts/prepare.mjs нужен только для синхронизации с исходной локальной структурой; автономная сборка не требует DEV-файлов.

Схема D1 — db/schema.ts; миграции — drizzle/. .openai/hosting.json сохраняет идентификатор публикации. Секреты модели задаются в окружении хостинга и не включаются в исходники.

Новый посетитель получает пустое рабочее пространство. Данные сессий разделены HttpOnly-cookie; изменения транзакционны, версия защищает от конфликтов. Для переноса между устройствами предусмотрены экспорт JSON и восстановление через загрузку данных. Корпоративная авторизация и общие пространства сотрудников не заявляются.

Импорт: JSON до 5 МБ, до 500 изменяемых записей за операцию, отдельная запись до 900 КБ. Ошибка или конфликт не перезаписывает существующие данные. Учебные фикстуры включаются только в автоматических тестах через ENABLE_DEMO=true, в публикации они выключены.

API модели зависит от квоты провайдера. Приложение показывает понятную ошибку, не сохраняет сбой как оценку и допускает ручную работу. DATASET_URL для загрузки по коду набора задаёт администратор; подписанная ссылка не публикуется.
