# Копия для GitHub

Проект размещён в папке «Анаис». Ветка для отправки: codex/anais.

Включены весь исходный код, инструкции, тесты, скриншот, 65 транскриптов DEV в data/dev.json и снимок локальных результатов в examples/state.example.json.

Ключи, .env и подписанные ссылки на API/аудио исключены. В пяти звонках audio_url установлен в null, добавлена причина. Исходные метки времени и тексты сохранены. Для прослушивания импортируйте исходный DEV локально в новом экземпляре приложения либо используйте локальную исходную копию проекта.

Запуск из этой папки: node --env-file-if-exists=.env server.mjs. Открыть http://127.0.0.1:3000. Для автоматической оценки скопировать .env.example в .env и настроить модель. Восемь критериев из файла команды подключены по умолчанию; отдельный PDF организаторов пока не предоставлен.

При первом запуске автоматически загрузятся транскрипты из data/dev.json. Снимок examples/state.example.json служит архивом ручной оценки; для восстановления в новом экземпляре скопируйте его в data/state.json до запуска сервера.

Обновление: checklist.official.json содержит восемь критериев; examples/manual-review.json — три явных ручных разбора RU/KZ/EN. Архив state.example.json относится к старой учебной версии.

Добавлены логотип команды, презентация, учебные сценарии и отчёт реальных API-проверок. Ключ находится только в локальном .env и не входит в эту копию. Запуск репозитория на другом компьютере требует своего API-доступа.
