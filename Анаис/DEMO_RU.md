# Защита CQA за пять минут

## До демонстрации

- Настроить реальную модель и официальный чек-лист. Проверить работу на нужных языках и аудиокритерии.
- Выбрать диалог с понятным доказательством, один пример N/A и критерий для пересмотра. Убедиться, что итог действительно изменится после пересмотра.
- Для спокойного показа заранее выполнить оценку. Затем в конце показать, что новая конфигурация применяется без изменения кода.
- Не представлять учебные критерии как официальные, а ручные результаты — как ИИ.

## 0:00–1:00 — интерфейс и диалог

«Система оценивает работу оператора по настраиваемому чек-листу. Здесь диалоги DEV на трёх языках, поиск, язык и канал. Откроем выбранный разговор». Показать транскрипт и роли. Для звонка показать плеер.

## 1:00–3:00 — результат и доказательства

Показать итог, секции и один критерий: ответ, вес, эффективный вес, вклад, объяснение. Нажать ссылку на реплику. Показать отсутствие действия через проверенный диапазон. На заранее подготовленном примере N/A объяснить перераспределение веса.

## 3:00–4:00 — апелляция

Нажать «Оспорить оценку», ввести комментарий, сохранить. Перейти в «Апелляции», открыть контекст, принять решение с причиной. Вернуться в карточку и показать новый итог и сохранённую исходную оценку.

## 4:00–5:00 — изменение критерия

В редакторе поменять формулировку или добавить критерий, сохранить новую версию. В карточке выбрать её и запустить оценку. Показать, что прошлый результат связан со старой конфигурацией. На зафиксированной версии кода новая конфигурация применяется через UI.

## Фактическое состояние поставки

По умолчанию подключён один основной чек-лист с восемью критериями из файла команды. Дискретные ступени, N/A, секции и грубые ошибки реализованы и проверены. 17 автоматических тестов проходят. Есть три явно ручных разбора синтетических диалогов на RU/KZ/EN; они не являются API-оценкой.

Модель пока не настроена: нужны ключ и название доступной модели либо работающий локальный сервер. Её качество на DEV не проверено. Отдельный PDF критериев не предоставлен; контрольный group_id и время старта неизвестны. Аудиоссылки в GitHub не публикуются, их нужно восстановить локальным импортом DEV. Для сценария изменения критерия можно добавить девятый критерий через UI; без модели результат оценивается только в ручном режиме и должен быть так обозначен.
