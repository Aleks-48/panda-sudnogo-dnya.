# Проверка CQA за пять минут

Презентация является отдельным файлом. В рабочем приложении нет вкладки презентации, оформления команды и предзагруженных учебных результатов.

## Подготовка

1. Открыть публичный CQA из README и загрузить JSON организаторов через «Загрузить данные».
2. Выбрать актуальный чек-лист, выполнить автоматическую оценку и сохранить результаты до выступления. При недоступной квоте нельзя выдавать ручную оценку за ответ модели.
3. Выбрать оценённый диалог с понятными доказательствами и примером N/A. Для звонка подготовить действующую аудиоссылку.
4. Скачать резервную копию JSON. Для переноса между браузерами загрузить её через «Загрузить данные».

## Регламент

| Время | Действие |
|---|---|
| 0:00–1:00 | Открыть карточку диалога; показать язык, роли и исходные метки времени. |
| 1:00–3:00 | Показать восемь критериев, вес, объяснение, переход к доказательству и пример N/A. Объяснить итог через формулу применимых весов. |
| 3:00–4:00 | Подать апелляцию с конкретным комментарием. Открыть её во вкладке «Апелляции», подтвердить или изменить ответ с причиной. Показать исходный и финальный баллы. |
| 4:00–5:00 | Изменить или добавить критерий через UI, сохранить новую версию, выбрать её и запустить оценку. Старый результат должен сохранить прежнюю конфигурацию. |

## Что сказать о проверках

22 теста приложения и 3 теста облачной версии прошли. После уточнения N/A на трёх опорных RU/KZ/EN примерах совпали 24 ответа по критериям. Это регрессионная проверка, а не независимая точность. Полный DEV-прогон получил 11 успешных оценок, затем был ограничен квотой API. Контрольный набор и отдельный PDF критериев необходимы для окончательной приёмки.
