# Анаис · Контроль качества Freedom Bank

Откройте index.html в современном браузере. В комплекте три вымышленных диалога. Для работы с API организаторов запустите из этой папки:

    python -m pip install pypdf
    python server.py --guide "путь к CQA_Hackathon_Student_Guide_v3 1.pdf"

Откройте http://127.0.0.1:8000. Если переменная CQA_DEV_URL содержит полный подписанный адрес DEV, достаточно команды python server.py без дополнительных пакетов. Храните подписанный URL вне Git.

## Проверка за пять минут

1. Откройте карточку о доставке карты. Выберите критерий и перейдите к реплике. Карта разговора показывает распределение текста по репликам. У звонка с audio_url появляется плеер.
2. Посмотрите вес, основание и итог. При N/A знаменатель уменьшается. Баллы по шкале пропорциональны весу, грубая ошибка учитывается отдельно.
3. В карточке критерия укажите причину апелляции. В разделе «Апелляции» откройте обращение, подтвердите или измените балл и сохраните основание. Проверьте обновлённый итог.
4. В «Чек-листе» измените критерий или добавьте свой. Укажите фразы на языках проверяемых диалогов. Сохраните и повторно оцените разговор.
5. В «Диалогах» загрузите JSON с массивом записей или ответом API. Для контрольной группы введите выданный group_id и получите данные через локальный сервер.

Оценка работает локально по объяснимым словарным правилам RU/KZ/EN. Платные вызовы отсутствуют. Правила дают предварительный вывод и могут пропустить контекст, ошибки консультации или перефразированную реплику. Для собственной семантики критерия настройте фразы поиска. Состояние хранится в localStorage текущего браузера. Прототип для хакатона, демонстрационные реплики не являются инструкциями банка.
